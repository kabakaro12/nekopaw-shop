# NekoPaw Shop — V0.1

Base technique bilingue FR/EN.

## Convention
- Code source: English
- SQL names: English
- Customer interface: French + English
- Business documentation/comments: French + English

## Start
```bash
npm install
cp .env.example .env.local
npm run dev
```

Then open:
- French: http://localhost:3000/fr
- English: http://localhost:3000/en
- Admin: http://localhost:3000/admin

## Database
Run `db/schema.sql` on PostgreSQL.
